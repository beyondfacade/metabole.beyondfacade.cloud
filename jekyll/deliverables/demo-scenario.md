# 7) 출품 시나리오

## 개발개요

메타볼레는 서울 상권 공공데이터를 구조화해 예비 창업자에게 **데이터 근거가 있는 창업 분석**을 제공하는 Hybrid RAG 에이전트 서비스다. 사업 배경과 차별점은 [사업 개요]({{ '/docs/business-overview.html' | relative_url }})와 [기대 효과]({{ '/docs/business-overview/effects.html' | relative_url }}) 참조.

## Data Flow (아키텍쳐링)

[상위 설계서 Data Flow]({{ '/docs/deliverables/high-level-design.html' | relative_url }})의 5단 구조(수집→적재→집계→서빙→AI 분석)를 출품 발표에서 1장 슬라이드로 사용한다.

## 목적과 기능

- 지도 기반 상권 탐색 — 행정동 427개 × 업종 10종 × 8개년 지표
- AI 창업 분석 리포트 — RAG 검색 + 도구 호출, SSE 스트리밍
- 정책자금 카드·금융 계산기 — 공공 근거 기반 정보 제공 (중개 없음)

## 대외 서비스 API 계획

현재 내부 API 중 대외 공개 후보와 조건:

| API | 내용 | 공개 조건 |
|---|---|---|
| `GET /regions/geojson` | 서울 행정동 경계 (경량화 GeoJSON) | 공개 가능 (공공 원천) |
| `GET /metrics` | 행정동×업종×연도 지표 | 공개 가능, 키 발급 + 호출량 제한 |
| `GET /funding` | 미만료 정책자금 공고 요약 | 공개 가능, 원문 출처 링크 포함 |
| `GET /shocks` | 특이변수 타임라인 | 공개 가능 |
| 에이전트 분석 (SSE) | AI 리포트 생성 | 비공개 유지 — LLM 비용·품질 통제, 데모 계정만 |

공개 시 인증키·레이트리밋·출처 표기(공공데이터 이용 조건)를 전제로 하며, 상세 정책은 출품 시점에 확정한다.

## DEMO (상세 설계에 맞는 데모시연)

**시연 흐름 (약 5분)**:

1. **지도 탐색 (90초)** — 접속 → 서울 코로플레스 → 업종 '카페' 선택 → 폐업률/성장률 지표 전환 → 시계열(2019~2026)로 코로나 충격 확인 → 후보 행정동 클릭, fact 카드 3장
2. **AI 분석 (150초)** — 선택 상권×업종으로 AI 분석 딥링크 → SSE 진행 패널(검색→도구 호출→작성) → 리포트: 지표 근거 + 특이변수(거리두기·금리) 맥락 + 관련 정책자금 카드
3. **금융 계산기 (60초)** — 월세 vs 매입 입력 → 공시금리·실거래 기반 손익분기 결과
4. **마무리 (30초)** — Recall@5 성능 수치, Data Flow 1장, 확장 계획(업종 추가 = 설정 추가)

**시연 리스크 대비**: 오프라인 대비 로컬 전체 스택 자립 구동(외부 의존은 공공 API뿐), LLM 실패 시 사전 생성 리포트 폴백, 데모 직전 [최종 검수]({{ '/docs/deliverables/final-inspection.html' | relative_url }}) 설치 절차로 리허설.
