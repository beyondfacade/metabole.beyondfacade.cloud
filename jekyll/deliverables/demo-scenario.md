# 7) 출품 시나리오

## 개발개요

“계약 전에, 피해야 할 동네와 업종부터.” 서울의 개업·폐업 기록으로 조합별 경고를 보여주고 근거·대안·리포트·자금 준비까지 이어가는 서비스입니다.

## Data Flow (아키텍쳐링)

[상위 설계서]({{ '/docs/deliverables/high-level-design.html' | relative_url }})의 수집 → 규칙 판정 → 사실 수집 → LLM 설명 도식을 사용합니다. 판정과 설명의 책임을 구분해 설명합니다.

## 목적과 기능

관문, 최신 경고 지도, 해당 시 대안, 6절 리포트, 지원 정보, 자금 계획이 시연 대상입니다. 현재 메인 지도에 없는 연도·지표 전환은 시연하지 않습니다.

## 대외 서비스 API 계획

| 내부 API | 용도 | 공개 상태 |
|---|---|---|
| `GET /regions/geojson` | 지도 경계 | 외부 제공 정책 별도 확정 필요 |
| `GET /verdicts?industry=` | 업종별 최신 판정 | 동일 |
| `GET /verdicts/{region_code}?industry=` | 동×업종 근거 | 동일 |
| `GET /verdicts/{region_code}/alternatives?industry=` | 조건을 만족하는 대안 | 동일 |
| `POST /analysis`, `GET /analysis/{id}/events` | 리포트 생성·스트림 | 모델 비용·인증·호출량 검수 필요 |
| `GET /funding/support`, `POST /finance/simulate` | 지원 안내·계산 | 외부 제공 정책 별도 확정 필요 |

라우트가 구현된 것과 공개 API 운영은 다릅니다.

## DEMO (상세 설계에 맞는 데모시연)

[최종 산출물 — 실제 구현 화면]({{ '/showcase/screens/' | relative_url }})을 시연과 함께 참고합니다.

**접속:** 실제 서비스는 [beyondfacade.cloud](https://beyondfacade.cloud)입니다. 문서 주소 `metabole.beyondfacade.cloud`는 앱 주소가 아닙니다. 로컬 시연 환경은 `http://localhost:3200`이며 원격 PC에서는 해당 서버 접근 설정이 필요합니다.

| 순서 | 시간 | 시연·설명 |
|---|---:|---|
| 1. 계약 전 질문 | 40초 | 관문에 “역삼동에 카페, 예산 5천” 입력. 후보 동이 나오면 직접 선택 |
| 2. 판정과 근거 | 70초 | 지도에서 등급·켜진 신호·산출일 확인. 대안이 있을 때 두 축 설명 |
| 3. 검증 결과 | 45초 | 카페 76.8% 대 38.2%, 표본·기준일·관찰 기간과 다른 업종 한계를 함께 설명 |
| 4. 리포트 | 75초 | 사실 자료와 설명 생성, 서울 전체 유사 사례 범위·출처 확인 |
| 5. 지원·계획 | 60초 | 완료 뒤 지원 화면 → 자금 계획. 비용 입력·계산·상담 준비 |
| 6. 구조·한계 | 30초 | 규칙과 LLM 역할, 제외 업종·보류·배포 상태를 마무리 설명 |

총 약 5분 20초이며 생성·연결 상태에 따라 달라집니다. 특정 동의 판정을 고정 대본으로 외우지 않고 시연 당일 산출일과 결과를 확인합니다.

### 실제 서비스 화면

![역삼1동 카페의 조건부 판정, 포화 신호와 대안이 표시된 실제 경고 지도]({{ '/assets/images/service-warning-map.png' | relative_url }})

2026-10-01, 기존 로컬 서버의 `/map?industry=cafe&region=1168064000`, 1440×1000 캡처. API 요청은 `/api/backend`이며 판정 산출일은 2026-09-30입니다. 화면은 캡처 당시 상태이고 실시간 결과를 보장하지 않습니다.

### 실패에 대비한 시연

연결·LLM 실패 시에는 실제 안내를 보여주고 이 문서의 화면 캡처와 [검증 결과와 원문 근거]({{ '/docs/evidence.html' | relative_url }})로 설명을 이어갑니다. 캡처를 실시간 결과로 소개하거나 자동 폴백 기능이 있다고 말하지 않습니다. 외부 LLM·지도 타일 의존이 있어 완전 오프라인 시연을 보장하지 않습니다.
