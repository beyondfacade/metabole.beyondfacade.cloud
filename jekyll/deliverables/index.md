# 6. 프로젝트 산출물

KDT 수업에서 요구하는 표준 산출물 6종을 정리한 장이다. 각 산출물은 수업에서 제시한 목차 골격을 그대로 따르되, 이미 이 사이트에 정리된 내용은 요약 후 해당 페이지로 링크를 걸어 이중 관리를 피한다.

1. [Milestone & WBS]({{ '/docs/deliverables/wbs.html' | relative_url }}) — 프로젝트 마일스톤과 작업 분해 구조
2. [요구사항 정의서]({{ '/docs/deliverables/requirements-spec.html' | relative_url }}) — 개발개요·주요 기능·고객 요구사항 3종
3. [상위 설계서]({{ '/docs/deliverables/high-level-design.html' | relative_url }}) — Data Flow·기술요소·요구사항별 구현목표
4. [상세 설계서]({{ '/docs/deliverables/detailed-design.html' | relative_url }}) — 요구사항별 구현방식 (구현 진행에 맞춰 갱신)
5. [시나리오 테스트]({{ '/docs/deliverables/test-scenario.html' | relative_url }}) — 단위→통합 테스트 시나리오와 TPS 측정
6. [최종 검수]({{ '/docs/deliverables/final-inspection.html' | relative_url }}) — 설치·이전·유지보수 방안
7. [출품 시나리오]({{ '/docs/deliverables/demo-scenario.html' | relative_url }}) — 대외 서비스 API 계획과 DEMO 시연
