# 2) 관련 서식

팀이 반복해서 쓰는 양식이다. 복사해서 채워 쓴다.

## 데일리 스탠드업 기록

[Sprint 일자별 진행 사항]({{ '/docs/schedule/sprint1.html' | relative_url }}) 표에 한 줄씩 쌓는다.

```markdown
| 날짜 | 요일 | 업무 내용 | 담당 | 상태 |
|------|:----:|-----------|------|:----:|
| MM.DD | 요일 | (한 일 / 할 일 / 막힌 일) | 이름 | ✅ 완료 · 🔄 진행 중 · 📋 예정 |
```

## 스프린트 회고 (Keep / Problem / Try)

```markdown
# Sprint N 회고 (MM.DD)

## Keep — 계속할 것
-

## Problem — 문제였던 것
-

## Try — 다음에 시도할 것
-
```

## 데이터 소스 검증 체크리스트

새 데이터 소스를 파이프라인에 붙이기 전에 채운다.

```markdown
# 데이터 소스 검증: (소스명)

- [ ] 인증키 발급 완료, 호출 제한(quota): ___회/일
- [ ] 업종코드 매핑 확인 (인허가명: ___)
- [ ] 좌표계 확인 (EPSG:5174 변환 필요 여부)
- [ ] 기존 데이터와 조인 키 검증 (주소/행정동/좌표)
- [ ] 시계열 커버리지: ____년 ~ 현재, 단절 구간: ___
- [ ] 갱신 주기: 일 / 월 / 분기 → 배치 주기: ___
- [ ] 라이선스·출처 표기 확인 (공공누리 유형: ___)
```

## 정책자금 공고 요약 카드 (표준 필드)

공고문에서 LLM으로 구조화 추출하는 필드 정의다. 카드 화면과 메타데이터가 이 필드를 공유한다.

```markdown
- 공고명:
- 기관:
- 대상 업종:
- 대상 지역:
- 대상 단계: 예비창업 / 기창업
- 한도:
- 금리:
- 마감일:
- 원문 링크: (필수)
```
