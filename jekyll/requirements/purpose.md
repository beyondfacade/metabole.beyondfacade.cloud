# 1) 목적

## 시스템이 답하는 질문

“계약하기 전에 이 동네·업종 조합에서 확인할 경고는 무엇이며, 근거는 무엇인가?”

현재 구현은 등급과 근거를 먼저 제시하고 해당하는 대안, 설명 리포트, 지원 정보, 자금 준비로 이어갑니다. 동네 전체나 개별 사업자의 능력을 평가하지 않습니다.

## 품질 요구 사항

| 영역 | 기준 | 검증 방법 |
|---|---|---|
| 판정 | 표본 부족을 경고 없음으로 바꾸지 않음 | 규칙 경계값·보류 우선순위 테스트 |
| 근거 | 신호 수치·원천·산출일 표시 | 판정 API와 카드 계약 대조 |
| 대안 | 현재보다 경고 순위가 낮은 후보만 표시 | 두 축 순위·제외·빈 결과 테스트 |
| 설명 | 판정 변경·수치 창작·인과 단정 방지 | 사실 선수집 계약·출처·생성 문장 검토 |
| 자금 | 가정·프리필·사용자 입력 구분 | 결정론 산식 및 입력 변경 회귀 검사 |

## 목표와 실측의 분리

Recall@5 91.5%와 지연 40% 개선은 초기 목표입니다. 현재 검색 평가 기록은 다중 정답을 반영한 Hit@5·MRR이며, 경고 판정 백테스트와 다른 질문을 검증합니다. 최신 서비스의 전체 응답시간·TPS를 이 목표로 대체하지 않습니다. [검증 결과와 원문 근거]({{ '/docs/evidence.html' | relative_url }})
