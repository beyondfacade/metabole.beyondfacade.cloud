# 7) 보안 및 개인정보 보호

## 개인정보 — 원칙: 모으지 않는다

- 분석에 쓰는 데이터는 전부 공공·개방 데이터다. 개인을 식별할 수 있는 데이터는 수집하지 않는다.
- 대출 계산기의 신용등급은 **사용자 자가 입력**만 받는다. 실제 신용정보 조회는 신용정보법·마이데이터 사업자 라이선스 영역이므로 MVP에서 절대 하지 않는다. 입력값은 계산에만 쓰고 저장하지 않는다.

## 금융 규제 경계 (금융소비자보호법)

대출 "중개·모집"은 금융소비자보호법상 등록 대상이다. 본 서비스는 중개까지 가지 않는다.

- 범위는 **공공 공고 기반 정보 제공 + 원문 링크**와 **계산기(시뮬레이션)**까지로 한정한다.
- 금리·한도 수치는 공고 원문 인용 또는 은행연합회 공시 데이터 인용으로만 표시한다. 자체 산출·확약은 금지한다.
- 계산 결과에는 "예상치이며 실제 심사 결과와 다를 수 있음"을 반드시 고지한다.
- 특정 은행 상품 추천·비교는 대출성 상품 중개에 근접하므로 하지 않는다. 공시 금리를 은행군 평균으로만 보여주는 것이 이 경계를 지키는 장치다.

## 차별적 출력 금지

- 외국인 거주 인구 등 민감 변수는 "수요 구성 변화 지표"로만 제시하고, "외국인 비율 높음 = 나쁜 상권" 류의 출력을 생성하지 않도록 응답 규칙에 명시한다.
- 이것은 서비스 신뢰와 법적 리스크(차별 조장) 문제이면서, 분석적으로도 틀린 결론을 막는 규칙이다. 실제 효과는 양방향이기 때문이다 — 기존 업종 수요는 줄어도 새 수요 업종과 에스닉 상권은 성장한다.

## 저작권·라이선스

- 뉴스는 전문을 저장하지 않는다. 메타데이터(제목·일자·언론사·URL)와 분석 지표만 저장하고 본문은 링크로 연결한다.
- 공공 공고는 대부분 공공누리 라이선스라 수집·재가공이 가능하나, 출처와 원문 링크를 반드시 표기한다.
- 스크래핑은 API가 없는 소스에만 쓰고, robots.txt를 준수한다.

## 시스템 보안

- API 인증키는 환경변수로 관리하고 저장소에 커밋하지 않는다.
- 외부 API 호출은 quota를 확인하고 캐싱으로 호출량을 줄인다.
- 배포 도메인(metabole.beyondfacade.cloud)은 HTTPS로 서비스한다.
