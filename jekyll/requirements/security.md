# 보안 및 개인정보 보호

## 공공 분석 데이터와 계정 데이터를 구분한다

상권 분석에는 공공 원천을 사용하며 서비스 전체에는 개인정보 수집도 포함됩니다. 현재 코드에는 회원 계정, 이메일·비밀번호 해시 또는 구글 로그인 식별, 세션, 접속·감사 기록, IP·디바이스 식별이 있습니다. 공개 안내와 보존 정책은 실제 운영 설정에 맞춰 별도 점검해야 합니다.

## 코드에서 확인한 통제

- 회원가입·로그인과 세션, 역할별 관리자 기능을 구분합니다.
- 구글 로그인은 authorization code·state·PKCE를 사용합니다.
- 접근 규칙, 자동 IP 차단, 로그인 제한과 접속·감사 기록을 둡니다.
- 사용자 디바이스 쿠키는 식별 보조값이며 인증 수단이 아닙니다.
- 관리자가 다른 계정의 비밀번호·등급을 변경하는 기능은 공개 관리 API 범위에서 제거했습니다. 운영자의 CLI 권한 관리는 별도입니다.

근거: `backend/apps/admin`, BE v0.49.0~v0.52.0 버전 기록. 이 문서는 보안 감사 통과를 주장하지 않습니다.

## 배포 시 확인할 항목

HTTPS 쿠키 설정, 프록시 전달 IP 신뢰 범위, 구글 OAuth 운영 리다이렉트 URI, 비밀값 관리, 로그·백업 보존 및 삭제 동작을 실제 배포 환경에서 확인해야 합니다. 문서 사이트의 HTTPS 접속만으로 앱의 설정이 완료됐다고 보지 않습니다.

## 정보 제공의 범위

지원 화면은 공고 후보와 원문을 안내하고 자금 계획은 사용자 입력·참고값으로 계산합니다. 신청 자격이나 대출 승인·금리를 확정하지 않습니다. 권리금은 사용자가 입력할 수 있지만 공공 원천으로 자동 추정했다고 표시하지 않습니다.

## 출처와 표현

뉴스는 제목·발췌·원문 링크 중심으로 사용합니다. 원천별 이용 조건과 상업 이용 가능 여부는 개별 확인이 필요합니다. 인구 집단의 특성을 경고의 원인으로 단정하거나, 통계적 차이를 인과로 표현하지 않습니다. 남은 검수 항목은 [최종 검수]({{ '/docs/deliverables/final-inspection.html' | relative_url }})에 있습니다.
