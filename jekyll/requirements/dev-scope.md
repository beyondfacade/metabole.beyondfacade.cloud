# 개발 범위

> 구현 기준: 2026-10-01, `feat/warning-copy` · `750b4e5` (BE v0.63.0 / FE v0.52.1). 운영 배포 완료를 뜻하지 않습니다. [검증 결과와 원문 근거]({{ '/docs/evidence.html' | relative_url }}).

## 지역·업종

서울 25개 구·427개 행정동을 기준으로 구현했습니다. 마스터 시드 18종, UI 선택 14종, 판정 12종을 구별합니다.

| 구분 | 업종 |
|---|---|
| 판정 제공 12종 | 카페·미용실·한식·중식·일식·양식·분식·호프·주점·노래방·PC방·헬스장·당구장 |
| UI에서 선택하지만 판정 제외 | 편의점·부동산중개업 — 재포함 백테스트 기준 미달 |
| UI 선택에서 제외한 보조 자료 | 학원·어린이집 |
| 수집·분류용 비노출 마스터 | 치킨·음식점 기타 |

## 현재 코드에서 확인한 기능

| 기능 | 상태와 조건 |
|---|---|
| 관문·지도 | 자연어 조건 입력, 후보 동 재질문, 최신 판정 단계구분도 |
| 근거·대안 | 신호와 산출일, 조건을 만족하는 다른 업종·같은 유형의 다른 동 |
| 폐업 마커 | 선택 동의 최근 2년 폐업 점포를 추가 표시 |
| 리포트 | 사실 선수집·6개 절·SSE 스트리밍·저장된 결과 |
| 지원 정보 | `/support` 공고·금리 참고값·상담 창구 |
| 자금 계획 | `/plan` 비용 입력·결정론 계산·최초안 비교·상담 준비 |
| 계정·관제 | 회원가입·로그인 및 권한에 따른 운영 화면 |

## 구현과 배포의 구분

위 기능은 확인한 브랜치의 코드 기준입니다. main 병합·외부 배포·실제 운영 가용성은 별도입니다. 실제 서비스 주소는 [beyondfacade.cloud](https://beyondfacade.cloud)로 사용자 확인을 받았습니다.

## 현재 제공하지 않는 것

- 메인 지도에서 연도·분기·지표를 전환하는 옛 탐색 UI
- 편의점·부동산중개업의 경고 등급, 모든 조합에 대한 대안 보장
- ML 기반 개인별 폐업 확률·매출 예측
- 은행 상품 추천·대출 승인·신청 대행

초기 “10업종”은 기획 당시 범위이며 현재 숫자로 소급 치환하지 않습니다.
