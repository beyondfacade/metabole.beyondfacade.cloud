# 2) 개발 범위

## 지역 — 서울 25개 구 (확정)

추정매출·시간대별 생활인구·개폐업률까지 완결된 공공데이터는 서울시 상권분석서비스가 유일하다. 그래서 서울에서만 풀 지표를 제공할 수 있다.

다만 확장 길은 미리 열어 둔다. 전국 공통 데이터(LOCALDATA·상가정보·실거래가) 기반 **코어 지표**와 서울 전용 데이터 기반 **확장 지표**를 코드 레벨에서 분리해, 추후 수도권·전국 확장 시 코어 지표는 데이터 추가 없이 동작하게 설계한다. 수도권(경기·인천) 확장은 post-MVP 후보다.

## 업종 — 10종 (핵심 3종)

업종 선정 기준은 "손님이 왜 오는가(수요 동인)"다. 핵심 3종은 수요 동인이 서로 다른 세 유형의 대표다.

| 수요 동인 유형 | 업종 | MVP 역할 |
|---|---|---|
| 일상소비형 (경쟁밀도 민감) | **카페**, 편의점, 미용실 | 기준 모델 |
| 여가형 (외생충격 민감) | **노래방**, PC방, 헬스장, 당구장 | 특이변수 검증 |
| 경기민감형 (거시변수 민감) | **부동산**(공인중개사무소) | 반례·일반화 검증 |
| 인구구조 민감형 | 학원, 어린이집 | 미래 인구 추계·정원/현원 |

구현·검증 순서는 유형당 대표 업종 먼저(카페 → 노래방 → 부동산 → 학원), 이후 같은 유형 내 업종은 설정 추가로 확장한다. 데모에는 평가셋 검증을 통과한 업종만 노출한다.

## 기능 범위

| 기능 | MVP | 비고 |
|---|---|---|
| 공공데이터 수집 파이프라인 | ✅ | 핵심 5종 + 보조 데이터 |
| Hybrid RAG + 분석 에이전트 | ✅ | Recall@5 91.5% 목표 |
| 브이월드 지도 시각화 | ✅ | 단계구분도·마커·상권 카드·시계열 슬라이더 |
| 정책자금 공고 요약 카드 | ✅ | 기업마당·중소벤처24·K-Startup 3개 API |
| 월세 vs 매입 대출 계산기 | ✅ | 계산까지만 (중개 금지) |
| 창업 비용 시뮬레이션 | ⚠️ 간이 버전 | 임대료 추정까지만 |
| 금융기관 제휴, 공제 연계 | ❌ | 계약·규제 검토 필요, post-MVP |

## 범위에서 제외 (MVP 이후)

- 서울 외 지역 (수도권 확장 포함)
- 확정 10종 외 업종
- 권리금 등 비공공 데이터
- 매출 예측 모델
- 뉴스 감성분석 등 NLP 고도화
