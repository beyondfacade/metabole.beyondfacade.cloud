# 대민 서비스 플랫폼 기능

> 구현 기준: 2026-10-01, `feat/warning-copy` · `750b4e5` (BE v0.63.0 / FE v0.52.1). 운영 배포 완료를 뜻하지 않습니다. [검증 결과와 원문 근거]({{ '/docs/evidence.html' | relative_url }}).

## 사용자 여정

| 단계·경로 | 동작 | 다음 단계로 가는 조건 |
|---|---|---|
| 관문 `/` | “역삼동에 카페, 예산 5천”처럼 조건 입력. `POST /intent`가 동·업종·예산 해석 | 동 이름이 모호하면 후보 선택. 지도 링크에 있는 값만 전달 |
| 경고 지도 `/map` | 업종별 최신 판정, 선택 동의 근거·산출일·동네 요약 | 대상 업종과 판정 데이터가 있어야 카드 표시 |
| 근거·대안 | 현재보다 경고 순위가 낮은 업종 또는 같은 유형의 다른 동 | clear는 대안 조회 없음. red·orange·보류도 적합 후보가 없으면 대안 없음 |
| 리포트 `/analysis` | 판정·이유·유사 사례·조건·대안·지원사업. 사실과 설명 스트리밍 | 리포트가 완료되고(`done`) 지역에 관한 사실(`facts.region`)이 있을 때 지원·지도 복귀 링크 |
| 지원 `/support` | 대출·보증, 자치구 전용, 창업·경영 공고 및 상담 창구 | 동·업종이 둘 다 있어야 자금 계획 버튼 표시 |
| 자금 계획 `/plan` | 비용 입력 → 필요 자금 → 상담 준비 | 동·업종 필수. 계산한 안이 있고 입력이 바뀌지 않았을 때 상담 준비 가능 |

리포트 → 지원 → 계획 링크는 동·업종·예산을 전달합니다. 지원 → 리포트 복귀도 같은 값을 유지합니다. 현재 계획 → 지도 복귀는 동·업종을 전달하며 예산은 포함하지 않습니다.

## 판정과 제외 상태

- **비추천(red)**: 판정 가능한 신호가 2개 이상이고 강한 판정 신호가 2개 이상입니다.
- **조건부(orange)**: 보류·비추천 조건에 해당하지 않고 켜진 판정 신호가 1개 이상입니다.
- **경고 없음(clear)**: 평가 가능한 판정 신호가 2개 이상이고 그중 켜진 신호가 없습니다. 성공·안전·추천을 보장하지 않습니다.
- **판정 보류(insufficient)**: 판정 가능한 신호가 2개 미만입니다. 경고 없음과 다릅니다.

편의점·부동산중개업은 UI 선택 목록에 있지만 판정 제외 사유를 안내합니다. 판정 미생성·404는 카드가 없을 수 있습니다. 동네 요약 조회와 판정 조회는 독립적이라 한쪽 실패를 다른 쪽 실패로 설명하지 않습니다.

## 지도와 대안

MapLibre 지도에 브이월드 배경 타일과 서버 GeoJSON 경계를 표시합니다. 메인 지도에는 연도·분기·지표 전환기를 두지 않습니다. 선택 동의 최근 2년 폐업 점포를 토글로 추가할 수 있습니다.

대안 후보는 clear·orange 중 현재보다 `(판정 순위, 강한 신호 수, 켜진 신호 수)`가 작은 조합입니다. 두 축 각각 최대 3개이며 성공 입지 추천이 아닙니다.

## 지원과 자금 계획

지원 공고는 관련 가능성이 있는 후보입니다. 신청 자격·금리·기간은 원문과 상담에서 확인해야 합니다. 공고 조회가 실패해도 상담 창구는 남깁니다.

계획에서는 보증금·권리금·인테리어·설비, 월 고정비와 예상 매출 등을 사용자가 입력합니다. 평균 매출·권역 임대료·ECOS 금리 프리필에는 출처와 한계가 붙습니다. 코드는 총 준비자금, 자기자본 외 조달 필요액, 손익분기 매출과 시나리오를 계산합니다. 희망 대출은 승인된 돈으로 간주하지 않습니다. 초안은 화면 상태로만 유지하며 다시 방문하면 빈 계획서로 시작합니다.
