# 5) 대민 서비스 플랫폼 기능

사용자가 실제로 만나는 화면과 기능이다. 프론트엔드는 웹(Next.js)으로 구현한다.

## 지도 화면 (브이월드 기반)

| 기능 | 내용 |
|---|---|
| 단계구분도 | 행정동별 폐업률/성장률을 색상 농도로 표시, 업종 토글 |
| 점포 마커 | 클러스터링된 업소 위치, 클릭 시 개업일·영업상태 |
| 상권 카드 | 행정동 클릭 → 업종 지표 요약 + 에이전트 분석 호출 버튼 |
| 시계열 슬라이더 | 2019 → 현재 연도별 변화. 코로나 충격과 회복이 한눈에 보인다 |

지표 정의(백엔드 산출):

- 성장률 = 당해 순증 점포 수 ÷ 전년 점포 수 (개업·폐업 모두 반영한 순증 기준)
- 폐업률 = 당해 폐업 수 ÷ 기초 점포 수

## 에이전트 대화 화면

- 지역·업종을 고르고 질문하면, 에이전트가 전통 변수와 특이변수를 나눠 진단한 분석을 근거 인용과 함께 답한다.
- 정형 지표는 "확인된 사실", 뉴스 신호는 "참고 신호"로 구분 표기해 신뢰도 혼동을 막는다.
- 어린이집처럼 인가제인 업종은 인가 절차 안내를 함께 제공한다.

## 정책자금 공고 카드

- 상권 분석 결과와 연계해 해당 업종·지역에 맞는 정책자금 공고를 요약 카드로 보여준다.
- 카드에는 대상·한도·금리·마감일과 **반드시 원문 링크**를 붙인다. 목표는 창업자가 공고를 찾아 헤매는 수고를 없애는 것이다.
- 예: *"이 상권 카페 폐업률이 평균 이상 → 초기 고정비를 낮추는 게 안전. 소진공 신규창업자금과 서울신보 특례보증 대상입니다 [공고 링크]"*

## 월세 vs 매입 대출 계산기

"지금 월세 300을 내는데, 이 상가를 매입하면 대출 이자가 월세보다 싸지 않나?"라는 비교를 계산까지만 제공한다.

1. **매입가 추정**: 국토부 상업용 실거래가에서 유사 면적 상가 시세
2. **금리 추정**: 은행연합회 공시 금리를 1군(시중)/2군(지방·인터넷·저축) 평균으로 집계, 사용자가 자가 입력한 신용등급 구간에 적용. 특정 은행 상품은 표시하지 않는다
3. **대출 가능액**: 상업용 담보 LTV 60~70% 가정 (가정임을 명시)
4. **월 부담 비교**: 원리금균등/이자만 납입 시나리오별 월 상환액 vs 현재 월세
5. **부대비용 포함**: 취득세(상가 4.6%)·중개보수·보유세까지 넣은 총비용과 손익분기 연차

출력 예: *"매입가 추정 4.2억, 자기자본 1.5억 + 대출 2.7억(공시 평균 연 5.2%) → 월 이자 약 117만원. 현재 월세 300만원 대비 월 183만원 절감, 부대비용 회수까지 약 1.1년"*

계산기가 상권 분석과 결합될 때 차별화된다. 폐업률 높은 상권이면 공실 리스크를, 성장 상권이면 시세 상승 여력을 근거 데이터와 함께 병기한다.

## 하지 않는 것

신용정보 실제 조회(자가 입력만), 특정 은행 상품 추천·비교, 대출 신청·중개. 경계의 근거는 [7) 보안 및 개인정보 보호]({{ '/docs/requirements/security.html' | relative_url }}) 참조.
