# Sprint 3 일자별 진행 사항 (09.17 ~ 09.30)

**상태: 완료** · **Sprint Goal: 에이전트와 데이터 맥락을 연결하고, 창업 경고 지도에서 리포트·지원·자금 계획으로 이어지는 흐름을 구현한다.**

팀에서 확인한 스프린트 완료 상태를 반영했습니다. 초반에는 에이전트·상권 탐색을 구현했고, 9/28 창업 경고 방향으로 전환한 뒤 9/29~30 판정·리포트·후속 화면을 확장했습니다. 아래 내용은 개발일지의 기록을 요약한 것으로, 스프린트 완료와 운영 배포·최종 검수 완료는 구분합니다.

## 검증 결과와 설계 결정

- **검색 평가:** 9/25 confirmed 180건 기준 Hit@5 1.000·MRR 0.95 기록을 확보했습니다. Sprint 2의 candidate 평가셋과 지표 정의가 다르므로 단순 증감률로 비교하지 않습니다.
- **창업 경고:** 9/29 카페 백테스트에서 비추천 집단과 경고 없음 집단의 3년 내 폐업률 비율은 2.01배였습니다. 업종별 차이와 작은 표본의 한계가 있으며 예측 정확도를 뜻하지 않습니다.
- **제외 업종:** 편의점·부동산중개업은 대리·집계 원천을 구현했지만 재포함 검증 기준에 미달해 판정 대상에 넣지 않았습니다.
- **유사 사례:** 자치구 단위 계산을 추가했다가 위양성 실측 후 철회했습니다. 현재 설명은 서울 전체 업종 범위로 한정합니다.

실험 조건·모집단·원문은 [검증 결과와 구현 근거]({{ '/docs/evidence.html' | relative_url }})에서 확인합니다. 이 문서를 작성하면서 앱 테스트나 실험을 다시 실행한 것은 아닙니다.
