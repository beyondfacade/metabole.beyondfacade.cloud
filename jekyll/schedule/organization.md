# 2) 조직 구성 및 역할 분담

팀 Beyond Facade는 김충식 팀장과 신채연·이은상 풀스택 개발자로 구성된 3인 팀입니다. 프론트엔드·백엔드를 개인별 전담 영역으로 나누지 않고 기능에 필요한 작업을 함께 진행했습니다.

## 역할 분담

| 이름 | 역할 | 담당 범위 |
|---|---|---|
| **김충식** | 팀장 | 프로젝트 방향·우선순위·일정 조율, 산출물과 최종 발표 준비 총괄 |
| **신채연** | 풀스택 개발 | 사용자 화면, API·데이터 처리, 서비스 연동·오류 수정 공동 개발 |
| **이은상** | 풀스택 개발 | 사용자 화면, API·데이터 처리, 서비스 연동·오류 수정 공동 개발 |

## 협업 방식

프론트엔드와 백엔드의 경계보다 사용자 기능을 기준으로 작업을 나눕니다. 두 개발자는 구현과 연동 문제를 함께 해결하고 팀장은 일정과 산출물을 조율합니다. 개인별 세부 기여는 작업·리뷰 기록으로 설명하며 위 역할표를 특정 기능의 단독 구현 실적으로 사용하지 않습니다.

## 마무리와 발표 준비

**2026-10-23까지 프로젝트를 마무리하고 10-27에 최종 발표**합니다. 마무리 전에는 기능과 문서를 검수하고 이후에는 발표 자료와 시연 동선을 함께 점검합니다. [단계별 개발 일정]({{ '/docs/schedule/timeline.html' | relative_url }})

# 2) 조직 구성 및 역할 분담

팀 Beyond Facade는 3인 체제로, 애자일 스크럼 기반의 수평적 조직으로 운영한다. PM이 스크럼 마스터를 겸하며, 개발 영역은 프론트엔드/백엔드로 나누되 AI 에이전트 개발은 두 개발자가 협업한다.

## 조직 구성

```
                ┌─────────────────────┐
                │   김충식 (PM)        │
                │ 프로젝트 관리 · 스크럼 │
                └──────────┬──────────┘
           ┌───────────────┴───────────────┐
┌──────────┴──────────┐         ┌──────────┴──────────┐
│      이은상          │         │      신채연          │
│  프론트엔드 (웹)      │         │      백엔드          │
└──────────┬──────────┘         └──────────┬──────────┘
           └───────────────┬───────────────┘
                ┌──────────┴──────────┐
                │  AI 에이전트 개발     │
                │  (이은상 · 신채연)    │
                └─────────────────────┘
```

## 역할 분담

| 이름 | 역할 | 주요 담당 업무 |
|------|------|----------------|
| **김충식** | PM · 스크럼 마스터 | 프로젝트 일정 및 백로그 관리, 스프린트 플래닝/리뷰/회고 진행, 품질 관리(테스트 시나리오·검수), 위험 관리, 문서화 총괄 |
| **이은상** | 프론트엔드(웹) · AI 에이전트 | 웹 앱(Next.js) UI/UX 설계 및 구현, 프론트엔드 상태 관리·라우팅, 에이전트 대화 UI, AI 에이전트 프롬프트 및 응답 품질 개선 |
| **신채연** | 백엔드 · AI 에이전트 | 공공데이터 수집/Chunking 파이프라인, 백엔드 API 서버(FastAPI), Hybrid RAG 파이프라인(임베딩·인덱싱·검색), 성능 튜닝, 서비스 배포 |

## 협업 방식

| 항목 | 내용 |
|------|------|
| 형상 관리 | GitHub (beyondfacade organization), PR 기반 코드 리뷰 후 병합 |
| 커뮤니케이션 | 데일리 스탠드업(15분) + 스프린트 리뷰/회고 |
| 작업 관리 | 스프린트별 칸반 보드 ([1) 단계별 개발 일정]({{ '/docs/schedule/timeline.html' | relative_url }}) 참조) |
| 완료 기준 (DoD) | 코드 리뷰 승인 + 테스트 통과 + 문서 반영 |
