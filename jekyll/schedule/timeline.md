# 1) 단계별 개발 일정

본 프로젝트는 **애자일 스크럼(Agile Scrum)** 방법론을 적용하여, 전체 개발 기간(2026.08.20 ~ 2026.10.27, 10주)을 **2주 단위 스프린트 5회**로 나누어 진행한다. 각 스프린트의 작업 항목은 칸반 보드로 관리한다.

> 💡 **쉽게 말하면**: 10주를 2주씩 다섯 토막으로 자르고, 토막마다 계획 → 개발 → 시연 → 반성을 반복합니다. 할 일은 To Do → In Progress → Review → Done 네 칸짜리 보드에 붙여 옮기며 관리합니다. 용어가 낯설다면 [용어 정의]({{ '/docs/appendix/glossary.html' | relative_url }})를 참고하세요.

---

## 스크럼 운영 방식

| 항목 | 운영 방식 |
|------|-----------|
| 스프린트 주기 | 2주 (총 5회) |
| 스프린트 플래닝 | 각 스프린트 시작일, 백로그에서 스프린트 작업 선정 |
| 데일리 스탠드업 | 매일 15분, 진행 상황 / 계획 / 장애 요인 공유 |
| 스프린트 리뷰 | 스프린트 종료일, 산출물 데모 및 피드백 |
| 회고 (Retrospective) | 리뷰 직후, Keep / Problem / Try 방식 |
| 칸반 보드 상태 | 📋 To Do → 🔄 In Progress → 👀 Review → ✅ Done |
