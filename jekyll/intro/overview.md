## 한 줄 소개

**메타볼(Metabole)** — 상권 데이터 구조화 및 창업 분석 Hybrid RAG용 Agent 개발 (공공 데이터 Chunking 기반 Recall@5 91.5% / Latency -40%).

코로나 이후 상권은 거리두기·영업제한 같은 **외생 충격**과 유동인구·임대료·경쟁밀도 같은 **전통적 상권 요인**이 겹치며 폐업과 회복을 반복해 왔습니다. 본 프로젝트는 **공공데이터**를 구조화(Chunking)하여 Hybrid RAG 파이프라인에 올리고, **초기 창업 희망자**에게 "이 지역에서 이 업종으로 창업해도 되는가"에 대한 근거 있는 분석을 제공하는 에이전트를 개발합니다.

## 지역 범위 — 서울 한정 (확정)

- 추정매출·시간대별 생활인구·개폐업률이 완결된 공공데이터는 서울시 상권분석서비스가 유일합니다.
- 전국 공통 데이터(LOCALDATA·상가정보·실거래가) 기반 **코어 지표**와 서울 전용 데이터 기반 **확장 지표**를 코드 레벨에서 분리해, 추후 수도권·전국 확장 시 코어 지표는 데이터 추가 없이 동작하도록 설계합니다.

## 타겟 업종 (10종)

수요 동인 유형 축으로 설계. **핵심 3종(카페·노래방·부동산)**은 수요 동인이 서로 다른 세 유형의 대표로, 하나의 분석 모델이 세 유형 모두에서 작동하면 일반화 가능성이 검증됩니다.

| 수요 동인 유형 | 업종 | MVP 역할 |
|---|---|---|
| 일상소비형 (경쟁밀도 민감) | **카페**, 편의점, 미용실 | 기준 모델 |
| 여가형 (외생충격 민감) | **노래방**, PC방, 헬스장, 당구장 | 특이변수 검증 |
| 경기민감형 (거시변수 민감) | **부동산**(공인중개사무소) | 반례·일반화 검증 |
| 인구구조 민감형 | 학원, 어린이집 | 미래 인구 추계·정원/현원 |

- 학원은 "학원 1업종 × 2축(교습계열 × 대상학년)" 서브카테고리 모델 — 교습계열은 서울시 학원·교습소 데이터(NEIS 원천) 원본 필드, 대상 학년은 교습과정명 LLM 구조화 추출.
- 업종 간 교차 시그널이 확장의 진짜 가치: 어린이집 폐원 → 초등 학원 수요의 선행지표, 편의점 출점 → "검증된 상권" 프록시, 여가형 3종(PC방·노래방·당구장) → 세대별 여가 수요 프로파일.

## 분석 변수 체계

전통 변수와 특이변수를 **분리된 축**으로 모델링합니다 — "상권의 기초 체력"과 "외부 충격 취약도"를 따로 보여줘야 창업자가 폐업의 원인(상권 자체 vs 일시적 충격)을 구분할 수 있고, 이것이 본 에이전트의 핵심 차별점입니다.

- **전통 변수 8종**: 유동인구, 배후인구, 경쟁점포 밀도, 개폐업률·생존율, 임대료·공실률, 접근성, 추정매출, 집객시설
- **특이변수 4계층**: ①정책·규제(거리두기, 최저임금, 주52시간 등) ②거시경제(금리, 물가, 에너지 요금) ③사회·트렌드(무인점포, 홈트 — 뉴스 언급량이 센서) ④지역 이벤트(GTX 개통, 재개발, 대형시설 개폐점)
- 재난지원금의 폐업 지연 왜곡(종료 후 폐업 절벽) 보정 원칙 수립
- 외국인 거주 인구는 "상권 악화 지표"가 아닌 **"수요 구성 변화 지표"**로 모델링 — 업종 타겟과 인구 구성의 정합성을 점수화하며, 차별적 출력 금지 규칙을 명시
- 뉴스 데이터(빅카인즈 1순위, 네이버 뉴스 API 보조)는 특이변수 감지 센서 + RAG 근거 문서로 활용

## 서비스 설계

### 브이월드(VWorld) 지도 시각화

브이월드는 배경지도(WMTS)·행정동 경계(WFS)·지오코딩을 제공하고, 성장률·폐업률 지표는 LOCALDATA 기반으로 자체 산출해 얹는 구조입니다.

- 행정동별 단계구분도(폐업률/성장률) + 업종 토글
- 점포 마커 클러스터링, 상권 카드(지표 요약 + 에이전트 분석 호출)
- 시계열 슬라이더(2019 → 현재) — 코로나 충격·회복 시각화

### 금융 연계

"들어가도 되나?"(분석)에서 "돈은 어떻게 마련하나?"(자금 조달)까지 한 흐름으로 잇습니다.

- **정책자금 공고 요약 카드 + 원문 링크** (MVP): 기업마당·중소벤처24·K-Startup 3개 API로 시작. 공고문을 LLM 구조화 추출(대상 업종·지역·한도·금리·마감일)하여 메타데이터화 — 신청·중개는 하지 않음(금소법 경계 준수)
- **월세 vs 매입 대출 계산기** (MVP, 계산까지만): 실거래가 기반 매입가 추정 × 은행연합회 공시 금리(1군/2군 평균) × 신용도 자가 입력, 취득세 등 부대비용 포함 손익분기 산출
- 금융기관 제휴·공제 연계는 post-MVP

## 주요 공공데이터 소스

- **상권 코어**: 소진공 상가정보, 행안부 LOCALDATA 인허가(개폐업), 서울시 상권분석서비스, 서울 생활인구, 국토부 실거래가
- **보조**: 한국부동산원 임대동향, 한국은행 ECOS, 은행연합회 공시 금리, 국세청 100대 생활업종, 지하철 승하차, KOSIS, 학원·교습소 정보(NEIS), 주민등록 인구통계, 외국인주민 현황, 어린이집정보공개포털
- **정책자금 공고** (API 검증 완료): 기업마당, K-Startup, 중소벤처24, 보조금24, 온통청년 — 5곳 API 확인 / 소진공·지역신보·서울시는 스크래핑 후보
- **뉴스**: 빅카인즈(한국언론진흥재단), 네이버 뉴스 API

## MVP 일정 (10주)

| 주차 | 내용 |
|---|---|
| 1~2주 | 공공데이터 API 검증, 업종코드 매핑표(10종), ERD 설계 |
| 3~4주 | 데이터 수집 파이프라인 + Fractal 11-File Set 구현 |
| 5~6주 | 전통 변수 산출 로직 + 상권×업종 분석 |
| 7~8주 | 특이변수(코로나·금리) 통합, Hybrid RAG Chunking |
| 9~10주 | 에이전트 응답 품질 평가(Recall@5 목표 91.5%), 데모 배포 |

**MVP 제외**: 서울 외 지역(수도권 확장 포함), 확정 10종 외 업종, 권리금 등 비공공 데이터, 매출 예측 모델, 금융기관 제휴.
