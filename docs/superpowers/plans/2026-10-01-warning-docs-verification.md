## 변경 내용과 독자 흐름

- 홈: 문제 → 실제 경고 지도 → 입력·판정·근거·후속 준비 → 조건이 붙은 백테스트 → 데이터·규칙·설명 구조 → 설계 선택 → 산출물.
- 소개·사업·요구사항·산출물·부록: 현재 코드가 제공하는 조건과 예외를 맞췄다. KDT 장·필수 문서 계층은 유지했다.
- `jekyll/evidence.md`: 업종별 표본·폐업률, 기준 시점·관찰 기간·한계, 별도의 RAG 평가와 고정 커밋 원문 링크를 모았다.
- ERD: ORM 47개 관계와 추가 11개를 보완했다. 기존 36테이블 실DB 명세·적재 수치는 날짜 있는 기록으로 구분했다.
- 일정·WBS·팀 역할: 현재 확인 범위와 과거 계획을 구분했다. 공식 종료일과 개인 기여를 임의로 확정하지 않았다.
- 공통 메타데이터·푸터·개발 일지 안내·홈 스타일을 정비했다. 새 프레임워크나 패키지를 추가하지 않았다.
- 한국어 검색: 기본 Lunr trimmer가 한글을 제거하는 문제를 테마의 공식 사용자 훅에서 수정했다. `_includes/lunr/custom-index.js`가 문자·숫자를 보존한다.

## 수치·주장 재대조

- UI 14 / 판정 12 / 마스터 시드 18을 다른 모집단으로 유지했다. 편의점·부동산중개업 제외를 명시했다.
- 보류 우선, 평가 가능한 신호 2개 이상, strong 2개 비추천, on/strong 1개 조건부, clear의 한계를 규칙 코드와 대조했다.
- 대안은 clear에서 조회하지 않고, 다른 상태도 적합 후보가 없으면 표시하지 않는 조건을 확인했다.
- 리포트 후속 링크는 `done && facts.region`, 지원에서 계획은 동·업종 필요, 계획에서 지도 복귀에는 예산이 없는 차이를 반영했다.
- 카페 76.8%(1,142) / 38.2%(1,680), 2.01배 및 업종별 표를 9/29 백테스트 원문과 대조했다. T=2022-06-30, `[T,T+365)` 진입, 개업 후 1,095일 폐업을 함께 썼다.
- 편의점·부동산 재심사의 경고/clear 기준 1.10배, 표본 각 50개업·30동 이상을 원문과 대조했다. 본문의 red/clear 비교와 구분했다.
- fp16·Ollama 검색 결과 파일에서 confirmed 180건의 Hit@5·MRR을 확인했다. 초기 Recall@5 91.5%·지연 40% 목표를 달성 실적으로 쓰지 않았다.
- 현재 검색의 pgvector·SQL 필터·뉴스 중복 처리를 코드로 확인했다. 초기 Hybrid RAG 제목은 유지하되 BM25 결합을 구현한 것으로 쓰지 않았다.
- 옛 문구 검색의 잔여 53개 위치를 확인했다. 과거 기록, 초기 과제명·목표, 현재 수치의 해석 한계, 지출 분류 같은 별개 모집단에 해당한다. 개발 일지와 초기 브레인스토밍도 읽고 보존했다.

독립 검토에서 `llm_call_event`의 토큰 기록 오기, 리포트 후속 링크 조건, clear의 평가 가능 신호 설명을 정정했다. 윤문 검토에서 ERD 과거 요약의 시점 표지를 추가했다.

## 확인이 필요한 사실과 미실행 범위

1. 공식 종료일: 기존 8/20~10/8(7주)와 8/20~10/27(10주)의 충돌.
2. 현재 팀 역할 및 개인별 실제 기여.
3. 공개 서비스의 정식 앱 URL. 문서 사이트와 구분했다. 이전 기록 후보 `metabole.beyondfacade.site`는 이 환경에서 DNS 조회에 실패했으며 확정 앱 링크로 사용하지 않았다.
4. main 병합·실배포 상태, 현행 운영 DB의 실제 테이블 수·최신 행 수는 확인하지 않았다.
5. 앱 전체 테스트, 백테스트, 검색 평가, 부하시험은 재실행하지 않았다. 저장된 실험 기록을 읽은 결과와 이번 문서 사이트 검증을 구분했다.
6. 전체 리포트 생성·실제 지원 신청·대출 승인 과정, 실제 모바일 기기는 검증하지 않았다.

로컬 검사 로그·화면·시작 상태는 `/tmp/metabole-docs-review/`에 있다. 이 임시 경로는 영구 산출물이 아니므로 핵심 결과와 제한은 이 문서에 기록했다.
